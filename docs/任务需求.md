LinkLayerAl 需要让扩展在安装并成功打开后，通知自己的服务器。然后 LinkLayerAl 服务器通知 Chesto。Chesto确认后自动发奖励。

## 用户流程

```text
用户打开 Chesto 任务
→ 安装 LinkLayerAl 扩展
→ 打开扩展
→ 返回 Chesto 点击「验证」
→ Chesto发送一次性验证码给扩展
→ 扩展把验证码发给 LinkLayerAl 服务器
→ LinkLayerAl 服务器确认扩展已经运行
→ LinkLayerAl 服务器通知 Chesto
→ Chesto自动完成任务并发奖励
```

## LinkLayerAl 扩展需要做什么

1. 允许 `chesto.ai` 检查扩展是否存在。
2. 第一次安装时生成一个随机 `installId`。
3. 接收 Chesto发送的一次性验证码。
4. 把验证码、`installId` 和扩展版本发给 LinkLayerAl 服务器。

扩展需要在 `manifest.json` 添加：

```json
{
  "externally_connectable": {
    "matches": ["https://chesto.ai/*"]
  }
}
```

## LinkLayerAl 服务器需要做什么

收到扩展的信息后，检查：

```text
扩展是否真的成功打开
Extension ID 是否正确
版本是否符合要求
这个安装是否已经领过奖励
如果需要，用户是否已注册或登录
```

检查通过后，LinkLayerAl 服务器向 Chesto发送一条带签名的确认消息：

```json
{
  "claimToken": "Chesto一次性验证码",
  "event": "extension_first_open",
  "extensionId": "官方扩展ID",
  "extensionVersion": "1.2.0",
  "installIdHash": "安装编号的哈希"
}
```

签名密钥只能放在 LinkLayerAl 服务器，不能放进扩展。

## Chesto需要做什么

Chesto检查：

```text
验证码是否正确
验证码是否属于当前用户和任务
LinkLayerAl 签名是否正确
扩展是否为官方扩展
这个用户和安装是否已经领过奖励
```

全部通过后：

```text
自动完成任务
→ 自动发放奖励
```

## LinkLayerAl 需要提供给我们

1. Chrome Web Store 链接。
2. 官方 Extension ID。
3. LinkLayerAl 服务器的对接接口。
4. 测试扩展或测试环境。
5. 明确完成条件：打开扩展，还是注册成功。

推荐把任务完成条件设为：

> 安装 LinkLayerAl 扩展并成功打开一次。

  扩展需要实现：

  1. 在 manifest.json 中添加：

  {
    "externally_connectable": {
      "matches": ["https://chesto.ai/*"]
    }
  }

  2. 首次安装时生成并持久化存储一个随机 installId。
  3. 记录以下时间戳：

  installedAt（安装时间）
  firstOpenedAt（首次打开时间）
  extensionVersion（扩展版本）

  4. 暴露外部消息监听器，接收来自 https://chesto.ai 的以下消息：

  {
    "type": "CHESTO_EXTENSION_VERIFY",
    "claimToken": "一次性验证码",
    "attemptId": "Chesto 验证尝试 ID",
    "taskId": "Chesto 任务 ID"
  }

  5. 将消息和安装证据转发至 LinkLayerAI 服务器。

  LinkLayerAI 服务器必须验证安装记录存在且扩展确实被打开过，然后调用：

  POST https://chesto.ai/api/action-verifications/webhooks/linklayerai
  Content-Type: application/json

  请求体（必填所有字段）：

  {
    "eventId": "唯一ID，重试时复用",
    "attemptId": "来自 Chesto 消息",
    "taskId": "来自 Chesto 消息",
    "claimToken": "来自 Chesto 消息",
    "event": "extension_first_open",
    "extensionId": "官方 Extension ID",
    "extensionVersion": "1.2.0",
    "installIdHash": "installId 的 SHA-256 哈希",
    "installedAt": "2026-07-16T10:00:00.000Z",
    "firstOpenedAt": "2026-07-16T10:00:05.000Z",
    "occurredAt": "2026-07-16T10:00:06.000Z"
  }

  Webhook 请求头：

  X-Provider-Key-Id: linklayerai-v1
  X-Provider-Timestamp: Unix 秒级时间戳
  X-Provider-Signature: sha256=<十六进制签名>

  签名计算方式：

  signingKey = SHA256(webhookSecret)
  signedContent = timestamp + "." + exactRawJsonBody
  signature = HMAC-SHA256(signingKey, signedContent)

  重要注意事项：

  - webhookSecret 只能保存在 LinkLayerAI 服务器端。
  - 绝对不能将其放入 Chrome 扩展中。
  - 不要将原始 installId 发送给 Chesto——只发送其 SHA-256 哈希值。
  - Webhook 重试时必须使用相同的 eventId。
  - LinkLayerAI 服务器必须验证安装/打开记录确实存在，而不能仅凭收到 claimToken 就批准。

  LinkLayerAI 提供 Extension ID 和 Chrome Web Store URL 后，Chesto 将提供：

  - 生产环境 webhook 凭据
  - Key ID
  - 非活跃的端到端测试任务
  - 测试说明
